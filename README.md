# Matplotlib Notes

Jupyter notebook of Matplotlib notes with runnable examples.

## Topics (`Matplotlib.ipynb`)

- 2D line plots, scatter plots, bar charts, histograms, pie charts
- Colored scatter plots, plot size, annotations, horizontal and vertical reference lines
- Subplots, 3D plots, contour and contourf, heatmaps
- Saving figures and plotting straight from Pandas

## Run it

```bash
pip install matplotlib pandas jupyter
jupyter notebook Matplotlib.ipynb
```
